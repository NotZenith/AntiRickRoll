# Troubleshooting Guide

### No audio detected
- Ensure your default playback device is correctly selected in Windows.
- Check if any other application is capturing audio in "Exclusive Mode".

### High CPU usage
- Reduce the FFT size in Advanced Settings.
- Disable real-time spectrogram visualization if not needed.

### False positives
- Increase the "Detection Confidence" threshold in Settings.
- Ensure you are not in a very noisy environment.
