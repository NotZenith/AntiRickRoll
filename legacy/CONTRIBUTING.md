# Contributing to AntiRickRoll

We love your help! To keep the project maintainable, please follow these guidelines.

## How to Contribute
1.  **Report Bugs:** Use the issue tracker. Provide clear reproduction steps.
2.  **Suggest Features:** We are always looking for ways to improve protection!
3.  **Submit Pull Requests:**
    - Fork the repository.
    - Create a feature branch (`feat/your-feature`).
    - Ensure all tests pass (`pytest`).
    - Run linting (`ruff check .`).
    - Follow the [Development Guide](docs/development.md) for setup.

## Branching & Commits
- Use descriptive branch names.
- Use [Conventional Commits](https://www.conventionalcommits.org/) (e.g., `feat:`, `fix:`, `docs:`).

## Pull Request Checklist
- [ ] Tests added/updated.
- [ ] Documentation updated.
- [ ] Linting and type checking pass.
- [ ] Screenshots provided for UI changes.
