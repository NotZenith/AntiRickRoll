# Security Policy

## Supported Versions

Currently, only the latest release is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| v0.5.x  | :white_check_mark: |
| < v0.5  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please do NOT open a public issue. Instead, report it privately via email to `security@antirickroll.org` (placeholder).

We will acknowledge your report within 48 hours and provide a timeline for a fix.

## Privacy Principles
1.  **Local Only:** AntiRickRoll does not upload audio, fingerprints, or metadata to any server.
2.  **No Telemetry:** We do not collect usage statistics or crash reports automatically.
3.  **Transparency:** All source code is open for auditing.
